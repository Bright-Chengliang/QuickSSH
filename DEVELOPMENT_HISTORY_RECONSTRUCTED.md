# Reconstructed development history

This branch is a curated reconstruction of the project's development stages from the current public source tree. The original development commits were not available in the local Git object database, so the commits here are organized by functional boundaries rather than restored from the original timeline.

`main` remains the canonical branch. This branch is provided for readers who want to inspect the project as a sequence of implementation stages:

1. Android project and dependency setup
2. Server profiles, workspaces, and credential storage
3. Persistent SSH terminal sessions
4. Observable SFTP transfer workflows
5. SSH tunnels and device settings
6. Terminal, transfer, and tunnel integration
7. Test coverage and local debugging helpers
8. Documentation and release presentation

No credentials, private keys, local runtime data, or ignored debugging artifacts are included in this branch.
